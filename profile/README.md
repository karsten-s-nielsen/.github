## OSTI — Open Standard for Training Interoperability

A FHIR-inspired schema and microservice pipeline for structured soccer session plans.

| Repository | Description |
|------------|-------------|
| [osti](https://github.com/karsten-s-nielsen/osti) | Core schema — Pydantic V2 models, JSON Schema, versioned data standard |
| [osti-segment](https://github.com/karsten-s-nielsen/osti-segment) | PDF segmentation microservice — spatial regions, text extraction, diagram cropping via VLM |
| [osti-parse](https://github.com/karsten-s-nielsen/osti-parse) | Text parsing microservice — segmentation output to structured OSTI SessionPlan |
| [osti-render](https://github.com/karsten-s-nielsen/osti-render) | Visualization CLI — annotated page analysis PNGs from segmentation and parse output |
